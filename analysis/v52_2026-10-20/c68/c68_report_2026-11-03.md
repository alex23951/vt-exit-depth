# C68: RE+ timing test on the frozen v5.1 control heart (PC report, 3 Nov 2026)

For the lock thread, under C68 (26 Oct 2026). This was a timing-only test, outside the hold. Nothing in its output folders was opened, plotted, scored or compared, and no ECG was computed. Driver: analysis/v52_2026-10-20/c68/c68_re_timing.py (3302bf8). LABNOTES entries 2 Nov 16:02-17:13 and 3 Nov 01:46-06:06 PC.

## 1. Settings (C68 (1)-(2)), logged before each run
**Inputs** were frozen v5.1 only:
- A copy made by `git archive v5.1` (d1ff89b), plus the monodomain check's params/v51_mono_conductivities.json and mono51.py at 6cdbabc.
- It sits in runs/v52_2026-10-20/c68_timing/v51_copy/; data/ and runs/ were read in place through symlinks.
- v5.1 was never checked out in the v5.2 tree.
- The v5.2 tree's git status changed during the test only by Decision 8's per_site.csv (committed at Alex's word for D37, 2bd6160), the C68 driver (committed) and LABNOTES. The test touched no tracked file.

**Model** (nothing tuned):
- Y5HYEDL4's v5.1 mesh, the monodomain check's biv51: 375,190 nodes, 1,939,909 elements.
- v5.1 fibres; v5.1 speeds 600 / 360 / 480 mm/s (dream.vel_l / vel_t / vel_n).
- Tomek cells; dt 10 us; the monodomain check's tuned conductivities as RE+'s diffusion term.
- RE+: dream.solve 1, eikonal physics region on tags 1-2, monodomain parabolic solve. No elliptic solve and no ECG.
- dream.fim.tol 0.001 and dream.fim.max_iter 1e9, as v5.1's acceptance C.
- Output: Vm every 1 ms plus act.igb. RE+ wrote no rpt file.

**Stimulus**:
- Site lv_septum_phi0_z0.25_d10, node 187798. It is the first septal site that is none of the 9 gate-9 sites, not the template site and none of bias_sites51.json's sites.
- 400 uA/cm3 x 1 ms on the 18 nodes within 1.5 mm at 0 ms.
- v5.1's junction exit times replayed one way, as mono51.graph_beat does: 3,518 exits in 209 bins of 0.25 ms, nodes within 1.0 mm. Total 210 stimuli.
- RE+ takes the stimuli as timed activation starts ("Only geometry, start time, npls, and bcl ... are used").

**Processes and build**:
- `mpiexec -n 1 openCARP`. Build: tag "latest", hash ffce19513ca90235192fff261160f53167921877, PETSc 3.25 (with HYPRE), no Ginkgo.
- ldd and the binary's symbols show no OpenMP runtime, so the thread sweep of C68 (2) does not apply: one single-threaded run per stage.
- CPU (lscpu): Intel i5-9300H, 4 physical cores, 8 logical.

**What changed between tries** (C68 (6)):
- Run (a)'s first try was refused at start, because openCARP will not take a stimulus that ends after -tend. Run (a) therefore keeps the 167 stimuli that end by 50 ms.
- Run (b)'s first try was paused at Alex's request at about 75 ms, then ended by an Ubuntu shutdown. Run (b) was rerun from 0 ms.
- Both earlier tries are kept and used for no figure.
